1. Постановка задачи
Вычислить значение математического выражения ((a + b)³ - (a³ + 3·a²·b)) / (3·a·b² + b³) при a = 1000, b = 0.0001 с использованием типов данных float и double. Вычисления выполнять с использованием промежуточных переменных. Сравнить и объяснить полученные результаты.
Вычислить значения выражений и объяснить полученные результаты при начальных значениях m = 10, n = 5:
n-- - m
m-- < n
n++ > m
2. Программа решения задания 1
#include <iostream>
#include <iomanip>

int main()
{
    setlocale(LC_ALL, "ru");

    double a_d = 1000.0;
    double b_d = 0.0001;

    double d_1 = ((a_d + b_d) * (a_d + b_d) * (a_d + b_d)) - (a_d * a_d * a_d + 3 * a_d * a_d * b_d);
    double d_2 = 3 * a_d * b_d * b_d + b_d * b_d * b_d;
    double result_d = d_1 / d_2;

    float a_f = 1000.0f;
    float b_f = 0.0001f;

    float f_1 = ((a_f + b_f) * (a_f + b_f) * (a_f + b_f)) - (a_f * a_f * a_f + 3 * a_f * a_f * b_f);
    float f_2 = 3 * a_f * b_f * b_f + b_f * b_f * b_f;
    float result_f = f_1 / f_2;

    std::cout << std::fixed << std::setprecision(15);
    std::cout << "--- float result ---" << std::endl;
    std::cout << "Числитель: " << f_1 << std::endl;
    std::cout << "Знаменатель: " << f_2 << std::endl;
    std::cout << "result: " << result_f << std::endl;

    std::cout << std::fixed << std::setprecision(7);
    std::cout << "--- double result ---" << std::endl;
    std::cout << "Числитель: " << d_1 << std::endl;
    std::cout << "Знаменатель: " << d_2 << std::endl;
    std::cout << "result: " << result_d << std::endl;

    return 0;
}

5. Объяснение результатов (Задание 1)
Математически данное выражение тождественно равно 1. Согласно формуле куба суммы, (a + b)³ = a³ + 3·a²·b + 3·a·b² + b³. Если вычесть из этого a³ + 3·a²·b, в числителе остаётся ровно 3·a·b² + b³, что в точности равно знаменателю.
Однако на практике наблюдается резкое расхождение результатов из-за катастрофической потери значимости (вычитания двух близких по величине больших чисел):
При вычислении (a + b)³ получается число порядка 1 000 000 300.
Тип float (32 бита) имеет мантиссу всего ~7 десятичных знаков. Он не может сохранить младшие разряды числа 1 000 000 300.0003, и они округляются. При вычитании 1 000 000 400.0 - 1 000 000 300.0 получается ошибочное значение 64.0 вместо истинных ~0.00003. Это приводит к абсолютно неверному итоговому результату (~2 133 333.5).
Тип double (64 бита) имеет мантиссу ~15–17 десятичных знаков. Он сохраняет больше значащих цифр, поэтому потеря точности менее критична, и результат оказывается близким к 1 (0.997...), хотя и не абсолютно точным из-за той же фундаментальной особенности арифметики с плавающей точкой.
6. Программа решения задания 2
#include <iostream>

int main()
{
    int m = 10;
    int n = 5;

    int a = n-- - m;
    std::cout << "1) n---m\t" << a << std::endl;
    
    bool b = m-- < n;
    std::cout << "2) n--<m\t" << b << std::endl; // В коде вычисляется m-- < n, но строка содержит опечатку
    
    bool c = n++ > m;
    std::cout << "3) n++>m\t" << c << std::endl;

    return 0;
}

8. Объяснение результатов (Задание 2)
Исходные значения: m = 10, n = 5.
n-- - m: Операция постфиксного декремента n-- возвращает текущее значение n (равное 5) для участия в вычислении, а затем уменьшает n на 1 (теперь n = 4). Вычисляется выражение 5 - 10, результат -5 присваивается переменной a.
m-- < n: Сравниваются текущие значения: m равно 10, а n равно 4 (после предыдущего шага). Условие 10 < 4 является ложным, поэтому результат выражения 0 (или false). После выполнения сравнения значение m уменьшается на 1 (теперь m = 9).
n++ > m: Сравниваются текущие значения: n равно 4, а m равно 9 (после предыдущего шага). Условие 4 > 9 является ложным, результат 0 (false). После выполнения сравнения значение n увеличивается на 1 (теперь n = 5).
