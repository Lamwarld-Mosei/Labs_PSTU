1)
O(n) — линейная.
У нас есть один цикл for, который выполняется ровно n раз. Внутри цикла выполняется константное действие (counter += 2).

2)
O(n) — линейная.
Здесь есть вложенный цикл. Но внутренний цикл выполняется всегда 10 раз. То есть общее количество операций равно n * 10. В Big O константы отбрасываются.

3)
O(n) — линейная.
Рекурсивная функция. При каждом вызове n становится меньше на 1, и создается один новый вызов. Функция вызовет саму себя n раз (пока n не станет равно 0).

4)
O(n + k) — линейная.
Здесь два независимых цикла. Первый выполняется n раз, второй — k раз. В таких случаях сложность складывается.
